# Phraselet Privacy Policy

Last updated: September 7, 2026

Phraselet saves words and phrases for later review. It does not use analytics, advertising, tracking pixels, or developer-operated servers.

## Data stored on your device

Phraselet stores the following in Chrome's local extension storage:

- Saved phrases and nearby page context
- Source page titles and URLs
- Notes, tags, learning status, and generated explanations
- Preferences and an optional OpenAI API key

This data is not designed to sync between browsers. Anyone with access to your Chrome profile or unlocked device may be able to access it.

## Page access

Phraselet accesses the active page only after you explicitly save a selection using the extension button, keyboard shortcut, or context menu. It uses that access to read the selected text and nearby context. It does not run persistently on every website.

## Optional OpenAI processing

AI explanations are disabled unless you add your own OpenAI API key. When enabled, Phraselet sends the saved phrase, nearby context, source title, and source-site hostname directly from the extension to OpenAI's API. It does not send the full source URL. Requests specify that the generated response should not be stored for later retrieval. OpenAI processes this data under its own applicable terms and privacy policies.

Phraselet does not send notes, tags, your library as a whole, or unrelated browsing history to OpenAI.

## Sharing and sale

Phraselet does not sell personal data. It does not share data with third parties except for the optional OpenAI processing described above.

## Your controls

You can export or delete individual saved phrases from the extension. You can remove your OpenAI API key in Settings. Clearing Phraselet's extension data or uninstalling the extension removes its locally stored data from that Chrome profile.

## Changes and contact

This policy may change when Phraselet's data practices change. Before public release, the publisher must add a support contact and publish this policy at a stable public URL.
