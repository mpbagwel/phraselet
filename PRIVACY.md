# Phraselet Privacy Policy

Last updated: October 10, 2026

Phraselet is published by Phraselet. Support is available at [mpbagwell.dev@gmail.com](mailto:mpbagwell.dev@gmail.com).

Phraselet saves selected words and phrases with their source context so you can organize and review them later. The public extension is local-first: it does not use analytics, advertising, tracking pixels, developer-operated servers, or third-party AI services.

## Information Phraselet handles

When you ask Phraselet to save a selection, it may handle:

- The text you selected
- Nearby text used as source context
- The source page title and URL
- Notes, tags, and archive state you add
- Extension preferences

Phraselet stores this information in Chrome's local extension storage on your device. It is not designed to sync between browsers. Anyone with access to your unlocked device or Chrome profile may be able to access it.

## Page access

Phraselet accesses the active page only after you explicitly invoke a save action using the extension button, keyboard shortcut, or context menu. It uses this temporary access to read the selected text, nearby context, page title, and URL. Phraselet does not run persistently on every website or collect unrelated browsing history.

## Sharing and sale

The public version of Phraselet does not transmit your saved library to Phraselet or another company. Phraselet does not sell personal data or use it for advertising.

## Your controls

You can edit, archive, restore, or delete saved phrases; apply the same actions to several phrases at once; export a restorable JSON backup; and create portable Markdown or CSV files. When you explicitly choose Copy in bulk-selection mode, Phraselet writes the selected phrase text to your system clipboard. You can restore compatible JSON backups through the import feature. Clearing Phraselet's extension data or uninstalling the extension removes its locally stored data from that Chrome profile.

## Data security

Phraselet limits extension storage access to trusted extension pages. Because the public version does not operate a remote service, Phraselet does not retain a server-side copy of your library.

## Chrome Web Store Limited Use

Phraselet's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Phraselet uses this information only to provide and improve its user-facing phrase-saving and organization features.

## Website analytics

The Phraselet website, including its homepage, support page, and this privacy page, uses Google Analytics to understand visits and improve the website. Google Analytics uses cookies and collects information such as pages viewed, traffic sources, browser and device information, and interactions with the website. This information is sent to Google. We also measure clicks on the homepage's Chrome Web Store link; a click does not tell us whether someone installed the extension.

Website analytics does not access your saved phrases, notes, source pages, or activity inside the Phraselet extension. The extension itself does not use analytics.

Read [how Google uses information from sites that use its services](https://policies.google.com/technologies/partner-sites). You can restrict cookies through your browser settings or use [Google's Analytics opt-out browser add-on](https://tools.google.com/dlpage/gaoptout).

## Changes

This policy may change when Phraselet's data practices or functionality change. Material changes will be reflected in this policy and, when required, disclosed through the extension or its store listing.
